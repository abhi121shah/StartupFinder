# 🚀 Startup Finder — Verified University Collaboration

> A privacy-first, verified student platform where university founders build teams in stealth mode and talented student candidates find meaningful startup projects.

---

## 📌 About the Project

**Startup Finder** solves a major problem on university campuses: student founders want to find skilled co-founders and team members, but hesitate to share unreleased startup ideas publicly for fear of idea theft. 

With **Startup Finder**, projects launch in **Stealth Mode** — public candidates only see the domain niche, stage, and open roles needed. Full confidential pitches, roadmaps, and milestones unlock **only after the founder reviews the candidate's application and grants access**.

---

## ✨ Key Features

### 🏗️ Founder Profile & Workspace
- **Zero Distractions**: Founders see only the projects they personally uploaded (cannot browse other founders' cards).
- **Tab 1 — My Uploaded Projects**: Track active projects, member counts, and live access request alerts.
- **Tab 2 — Add New Project**: Form to upload projects with stealth pitch, target domain, development stage, and open roles.
- **Tab 3 — Manage Members & Access**: Review candidate applications, motivation notes, and **Grant / Revoke Access** with one click.

### 🔍 Candidate Profile & Portal
- **Tab 1 — Browse Projects**: Explore startups filtered by niche (EdTech, GreenTech, FinTech, SaaS, etc.) and open roles in **Stealth Mode**.
- **Role-Specific Join Requests**: Submit applications and motivation notes directly to founders.
- **Tab 2 — Joined Projects**: Projects where access was granted display full unlocked roadmaps, milestones, and team members.
- **Tab 3 — Candidate Profile**: Student identity verification and skills portfolio.

### 🎨 Modern Glassmorphism UI & Themes
- **High-Transparency Glassmorphism**: Frosted glass effects with backdrop blur over custom desk & workspace wallpapers.
- **☀️ Light / 🌙 Dark Mode**: Top-right floating toggle button with persistent theme memory (`localStorage`).
- **Responsive Layout**: Fluid design supporting desktop, tablet, and mobile views.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript (ES6+)
- **Styling**: Modern CSS3 (CSS Variables, Flexbox, Grid, Backdrop-Filter Glassmorphism)
- **Typography**: Google Fonts (*Space Grotesk*, *Inter*, *IBM Plex Mono*)
- **Storage**: Browser LocalStorage for persistent theme preferences
- **Zero Dependencies**: Pure web standards — runs instantly in any browser without build tools or node modules!

## 🚀 Quick Start / How to Run

1. Clone or download this repository:
   ```bash
   git clone https://github.com/your-username/startup-finder.git
   ```
2. Open the project folder:
   ```bash
   cd startup-finder
   ```
3. Open `index.html` in any web browser (or use VS Code Live Server):
   - Double-click `index.html` or drag it into Chrome / Edge / Firefox.
